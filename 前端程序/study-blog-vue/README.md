# 博客与学习系统前端

这是一个 Vue 3 + Vite 单页应用：`/` 为博客首页，主按钮进入 `/study`；注册、邮箱验证、登录、课程和 HTML 练习位于同一个应用中。

## 启动

```powershell
npm install
npm run dev
```

开发服务器会将 `/api` 转发到 `http://127.0.0.1:8000`。生产部署时让 Nginx 同源代理 `/api`，从而保留安全 Cookie 的同域模型。

## 测试策略

日常开发采用“目标测试 + 最小回归”，不要求每实现一个独立功能就跑完整前端测试集。

```powershell
# 只运行本次改动直接覆盖的测试文件
npm test -- tests/lesson-practice.test.js

# 完整前端回归（功能完成、提交前或修改共享逻辑时执行）
npm test
```

以下改动必须执行完整前端回归：共享组件或工具函数、路由和会话启动、认证与权限、公共 API 客户端、构建配置，以及一次功能开发完成后的最终验收。目标测试通过只说明本次改动覆盖的路径正常，不能替代完整回归或真实浏览器验收。
